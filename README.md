# awesome-seu-tools

收集并整理东南大学（SEU）师生常用的小工具与脚本，包含命令行脚本、Windows/Unix 工具、网页/自动化小程序等，方便分享与协作。

主要目标
- 汇总校园常用的小工具（网络查询、课表/成绩辅助、学习/生活小脚本等）
- 提供简单可复用的脚本和使用示例
- 鼓励社区贡献与分类管理

仓库结构
- tools/
  - scripts/        - 小脚本（Python、Shell、PowerShell 等）
  - web/            - 前端/后端轻量工具或演示
  - windows/        - Windows 相关工具（.bat/.ps1）
  - linux/          - Linux 专用脚本或服务配置
- examples/         - 使用示例与演示
- .github/ISSUE_TEMPLATE/ - issue 模板
- CONTRIBUTING.md   - 贡献指南
- LICENSE           - MIT 许可

快速开始
1. 克隆仓库并进入目录：
   git clone <repo-url>
   cd awesome-seu-tools

2. 运行示例脚本（示例使用 Python）：
   python3 tools/scripts/example.py

如何贡献
- 请先阅读 CONTRIBUTING.md
- 新增工具请放在 tools/ 对应子目录，提交 PR 时附上使用说明与示例
- 对列出的工具进行代码审查或改进时请遵循仓库编码规范
