# awesome-seu-tools 仓库索引

> 将本仓库作为“元工具”加入工具集，方便贡献者快速了解结构、维护方式与使用场景。

## 工具概览
- **类型**：元信息 / 仓库模板
- **适用场景**：需要查找东南大学相关脚本、分享现有工具、协作维护校园常用方案
- **主要功能**：
  - 汇总 SEU 校园常用工具与脚本，提供统一的分类目录
  - 为贡献者提供一致的文档模板与提交规范
  - 在主 README 中展示工具清单，便于发现与导航

## 使用方式
1. 阅读仓库根目录的 [README](../../../README.md) 了解仓库目标、结构与贡献流程。
2. 浏览 [`tools/`](../../) 目录，根据分类查找已有工具或在 `meta/` 下查阅维护类文档。
3. 通过 [`docs/TOOL_TEMPLATE.md`](../../../docs/TOOL_TEMPLATE.md) 快速创建符合规范的新工具文档。

## 验证步骤
- 检查 `tools/` 目录是否按分类划分，并确认对应文档完整。
- 打开主 README，确认“工具目录”表格能够展示该元工具条目。
- 提交或审阅 PR 时参考 [CONTRIBUTING.md](../../../CONTRIBUTING.md) 的流程与注意事项。
