# SEUCourseShare 课程共享计划

> 汇总东南大学各院系课程资料、复习经验与资源的社区协作型仓库。

## 背景
- 许多课程资料与考试经验散落在学长学姐个人存档，难以集中获取。
- 项目通过 GitHub 仓库按院系建立分支，方便贡献者维护所属院系的资料。
- 面向东南大学在校生，为课件整理、复习资料与经验分享提供统一入口。

## 功能特性
- **按院系分支管理**：通过 Git 分支划分院系，减轻单仓库体量过大带来的维护压力。
- **丰富的学习资料**：涵盖通识基础课、专业课程的参考资料、复习笔记与经验分享。
- **灵活的下载方式**：支持整仓库克隆、按分支下载、单文件夹或单文件下载。
- **开放协作**：任何同学均可 fork 后按指南贡献本学院资料，并重写分支内的说明。

## 环境要求
- Git 客户端（命令行或图形界面均可）。
- 如需批量下载，可配合 [DownGit](https://minhaskamal.github.io/DownGit/#/home) 等在线工具。

## 快速开始
```bash
# 克隆仓库
git clone https://github.com/zjdx1998/seucourseshare.git
cd seucourseshare

# 查看可用院系分支
git branch -a

# 切换到目标院系（示例：网络空间安全学院）
git checkout 57-网络空间安全学院
```

## 使用说明
1. 在 GitHub 页面点击 **Branch**，选择目标院系或课程类别分支。
2. 如需整分支资料，可使用 "Clone or download" → "Download ZIP" 直接获取。
3. 下载单个文件夹：复制该文件夹的地址（如 `https://github.com/zjdx1998/seucourseshare/tree/57-网络空间安全学院/参考书籍`），在 DownGit 粘贴并下载。
4. 下载单个文件：打开文件详情，若页面提供 **Download** 按钮可直接下载；否则点击 **Raw** 并使用浏览器的“另存为”功能保存。
5. 上传课件等受版权保护的内容时，请使用网盘并设置访问密码，尊重授课教师的劳动成果。

## 常见问题
| 问题 | 解决方法 |
| --- | --- |
| 分支过多难以维护？ | 每个院系独立维护对应分支，贡献者在提交前可先同步上游更新，避免冲突。 |
| 大文件无法直接上传？ | 建议上传到百度网盘等服务并在 README 中提供带密码的分享链接。 |
| 不熟悉 Git 操作？ | 参考仓库根目录提供的《贡献方法.md》或相关 Git 入门教程。 |
